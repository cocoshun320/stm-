# STM32 一键安装程序

> 将 **CH340 驱动 + JRE 8 + STM32CubeIDE** 三个安装包打包为一个 exe，双击即可完成全部安装。

## 功能特性

- **一键安装**：将三个安装包嵌入一个 exe，无需逐个点击
- **智能检测**：自动检测是否已安装，已安装的组件自动跳过
- **边释放边安装**：释放一个安装一个，安装完立即清理临时文件
- **异常检测**：检测安装程序意外终止并报告失败
- **自定义图标**：蓝色芯片风格图标

## 下载使用

1. 前往 [Releases 页面](https://github.com/cocoshun320/stm-/releases) 下载 `stm install.exe`
2. **右键 → 以管理员身份运行**（否则驱动可能安装失败）
3. 程序会依次安装三个组件，已安装的自动跳过

> **注意**：文件约 **1.15 GB**，因为内嵌了三个安装包。

## 包含组件

| 组件 | 版本 | 说明 |
|------|------|------|
| CH340 串口驱动 | - | USB 转串口驱动，用于连接 STM32 开发板 |
| Java Runtime Environment | 8u503 | STM32CubeIDE 运行依赖 |
| STM32CubeIDE | 1.17.0 | STM32 官方集成开发环境 |

## 已安装检测方式

| 组件 | 检测方式 |
|------|---------|
| CH340 | 驱动文件 `CH341SER.SYS` / 注册表服务 / Uninstall 项 |
| JRE 8 | 注册表 `JavaSoft\JRE\1.8` / 常见路径 `java.exe` / PATH 环境变量 |
| STM32CubeIDE | 安装目录 `C:\ST\STM32CubeIDE_1.17.0` / Uninstall 项 |

## 从源码编译

### 环境要求

- **MinGW-w64 GCC**（推荐 [WinLibs](https://github.com/brechtsanders/winlibs_mingw/releases)）
- 解压到 `C:\mingw64`，确保 `g++` 在 PATH 中

### 编译步骤

1. 将三个安装包放入 `程序/` 目录：
   ```
   程序/
   ├── CH340SETUP.EXE
   ├── jre-8u503-windows-x64.exe
   └── st-stm32cubeide_1.17.0_23558_20241125_2245_x86_64.exe
   ```

2. 双击 `build.bat` 或手动编译：
   ```bash
   windres resource.rc -O coff -o resource.o
   g++ -O2 -o "stm install.exe" installer.cpp resource.o -static
   ```

### 重新生成图标

```bash
g++ -O2 -o gen_icon.exe gen_icon.cpp
./gen_icon.exe    # 生成 icon.ico
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `installer.cpp` | 主程序 C++ 源码 |
| `resource.rc` | 资源文件（嵌入3个安装包 + 图标） |
| `icon.ico` | 自定义图标（6种尺寸：16~256px） |
| `gen_icon.cpp` | 图标生成程序源码 |
| `build.bat` | 一键编译脚本 |

## 技术细节

- **资源嵌入**：使用 Windows 资源文件（.rc）将三个!个 exe 作为 `INSTALLER` 类型资源嵌入
- **释放机制**：运行时通过 `FindResource` / `LoadResource` 释放到 `%TEMP%\stm_installer\`
- **进程等待**：`CreateProcess` + `WaitForSingleObject` 等待安装完成
- **异常检测**：通过进程退出码判断（`>= 0x80000000` 为异常终止）
